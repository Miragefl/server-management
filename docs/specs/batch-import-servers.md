# 批量导入服务器（batch-import-servers）

## 目标
支持区间表达式一次生成批量服务器（hostname/IP 各自递增、OS 统一设定），免除逐台新增。

## 约束
- 技术栈不变：SwiftUI + JSON 存储，无第三方依赖
- 单段容错：某段解析失败只跳过该段并在结果中明示，不中断整批
- 与现有数据无耦合，不动 Store 既有接口签名

## 模块拆解
- 表达式解析器 `ServerRangeParser`：纯函数，输入逗号分隔的段列表，每段 `前缀起始数~结束数` 或单值，展开为有序值数组（如 `yd-vm121~125` → yd-vm121…125）
- Store：`addServers(_:) -> (added, skipped)` 批量插入（hostname 或 IP 与现存重复则跳过）
- 导入视图 `ServerImportView`：hostname 表达式框 + IP 表达式框（各带占位示例与展开预览）+ OS 统一选择（常用模板菜单）+ 导入结果反馈
- 入口：服务器列表工具栏「+」改为菜单（单台新增… / 批量导入…）

## 数据模型
- 无 schema 变更，复用 `Server`
- 设计遵循：解析器独立纯类型，单测覆盖区间/单值/混合段/非法段等边界

## 关键决策
- 段格式 `前缀数~数`（结束数仅数字，前缀由起始侧继承）：贴合 `yd-vm121~125`、`10.137.32.121~125` 书写习惯，规则最简
- hostname 与 IP 展开后按**总数相等、顺序配对**：比逐段强制配对更灵活（一侧一段、另一侧多段也行）
- 分隔符接受英文逗号/全角逗号/分号：兼容中文输入法
- 重复判定 hostname 或 IP 任一重复即跳过该台：避免误造重复机器，结果中明示
- 展开实时预览：输入即显示将生成的前 N 条与总数，防呆

## 风险
- 跨位宽递增（yd-vm9~11）：按数字原样递增，接受 yd-vm9/10/11 与 yd-vm09~11 的位宽差异不抹零
- 超大区间误输（~99999）：预览显示总数，超过 500 拒绝导入并提示
- IP 段结尾非数字或非法段：该段进失败列表，不影响其余段
